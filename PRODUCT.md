# Между волн
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Implementation choice: buildless HTML, CSS and JavaScript modules. No runtime dependencies or paid APIs.
## Users
A tabletop game host prepares transmissions. Players explore the airwaves using a virtual receiver. The user requested a working first version; recordings will arrive later.
## Product Purpose
Make tuning a fictional radio into an interactive part of a tabletop session.
## Operating Context
One receiver on one shared device; browser-local preparation. No cross-device synchronization in this version.
## Capabilities and Constraints
Frequency tuning, generated static and demonstration signals, volume, noise, player view and host transmission editor. Audio files can be attached later. Store settings and files in IndexedDB and disclose storage failures. Never reveal station names or their frequencies in player view.
## Evidence on Hand
Conversation brief only. No recordings, visual brand or game script supplied. Example station names and synthesized signals are illustrative.
## Product Principles
- Put the playable receiver first.
- Keep the host's spoilers out of the player view.
- Let controls respond immediately to pointer, touch and keyboard input.
- Say clearly when settings are only in this browser.
