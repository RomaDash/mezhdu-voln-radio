# Между волн

Игровой радиоприёмник для настольных сессий. Статический сайт без зависимостей: настройка 87.5–108 МГц, помехи, аудиозаписи, пульт ведущего и режим игрока.

## Запустить

Из этой папки выполнить `npm start`, открыть http://127.0.0.1:4173 и нажать питание. Звук запускается только по нажатию. `npm test` проверяет аудиожизненный цикл, звуковые отклики, настройку частоты и валидацию станций.

## Музыка

- 91.4 — Night on the Docks - Sax, Kevin MacLeod, джаз.
- 98.2 — Cyborg Ninja, Kevin MacLeod, электроника / чиптюн.
- 104.7 — Gymnopedie No. 1, Erik Satie, исполнение Kevin MacLeod, фортепиано.

Авторские первоисточники, лицензия CC BY 4.0 и изменения формата перечислены в `dist/assets/music/credits.json` и в пульте ведущего. Записи полные, перекодированы в MP3 160 кбит/с. Новые записи загружаются через пульт; можно создавать слоты без файла.

## Хранение и ограничения

Настройки и Blob-файлы сохраняются в IndexedDB данного браузера. На другом устройстве эфир свой. Передача экрана или самого устройства подходит для общей игры; удалённой синхронизации ведущего и игроков нет. Режим игрока скрывает пульт и подсказки, выход — кнопкой или Escape. Это защита от случайных спойлеров, без пароля.

Обычная перезагрузка сохраняет успешно записанные передачи и файлы, но сбрасывает питание, частоту и позицию воспроизведения. Очистка данных сайта удалит эфир; приватный режим браузера не подходит для постоянного хранения. Локально добавленная запись не загружается в GitHub и не появляется у других людей по общей ссылке.

Кнопки сопровождаются тихими синтезированными щелчками; питание и пошаговая настройка имеют свои отклики. Значок динамика рядом с питанием отключает только звуки управления. Общая громкость на нуле заглушает также отклики. Выбор включения откликов запоминается в этом браузере отдельно от аудиозаписей.

Раздавать нужно папку `dist/` через HTTP, открытие ES-модулей двойным кликом по HTML не поддерживается. Внешние сервисы для проигрывания музыки не нужны: все три файла и шрифт включены в сайт.
